# Kun Finance

AI-powered cash flow forecasting for small businesses in Indonesia & Southeast Asia.
Part of the Kun projects ecosystem (Kundesk and Kun Bookshop).

## Status

🚧 Phase 1 — Tooling Foundation (in progress)

## Structure

```
/client   Next.js 16 frontend (TypeScript, Tailwind, next-intl)
/server   Express API backend (TypeScript, Prisma, PostgreSQL)
/ml       Python ML pipeline (forecasting + anomaly detection)
/docs     Project documentation
```
